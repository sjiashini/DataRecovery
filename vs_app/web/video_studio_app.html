⚠️ Pen Drive / Optical Drive USB Binding (PowerShell Admin)
usbipd list → find the BUSID of your pen drive or optical drive:
usbipd bind --busid <BUSID> (admin, once per USB port — survives reboot)
usbipd attach --busid <BUSID> --wsl
usbipd detach --busid <BUSID> — while attached the drive lives in WSL2 and is deliberately hidden from This PC; detach (or use the release button above) to get it back.

STOP USING the pen drive immediately — every new write overwrites recoverable data. Quick-formatted drives (the Windows default) are usually highly recoverable; full formats that zero-fill the flash are not.

API Endpoint Documentation

  • POST /api/cut - Execute instant stream copy cut or NVENC cut
  • POST /api/join - Execute VOB bitwise copy or FFmpeg demux concat
  • POST /api/transcode - Trigger HandBrakeCLI NVENC transcoding
  • POST /api/media_cancel - Stop the running cut, join or transcode (partial output removed)
  • GET /api/drives - List optical + USB flash drives attached to WSL2 (flags Windows USB devices that still need sharing)
  • POST /api/usbipd_bind - Share/attach one USB storage bus ID with WSL2 (single UAC prompt, validated bus ID)
  • POST /api/usbipd_release - Detach one USB storage bus ID from WSL2 so Windows regains it and it shows in This PC again
  • GET /api/tools - WSL2 toolchain check (ddrescue / photorec / testdisk)
  • POST /api/recover_all - Full async pipeline: image → carve (GET /api/recovery_progress to poll). Add {"carve": false} for imaging-only (Step 1), or {"skip_imaging": true} to carve an existing image (Step 2)
  • POST /api/recovery_cancel - Cleanly stop the running recovery (mapfile kept, resumable)
  • POST /api/testdisk - Open interactive TestDisk for undelete with original filenames
  • POST /api/open_folder - Open a recovery folder in Windows Explorer

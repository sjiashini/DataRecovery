How recovery works

One click runs all three stages as a single job, with live progress, a cancel that keeps your work, and a resumable image if anything stops it.

  1. Image the drive

    Every readable sector is copied to an image file, then damaged areas are retried. A mapfile records progress, so an interrupted run picks up where it stopped.

    ddrescue · 2048-byte sectors for discs, 512 for pen drives

  2. Analyse partitions

    The image's partition table is read without changing anything. TestDisk can also restore original file names for deleted files whose entries survive.

    TestDisk · read-only analysis

  3. Carve the files

    Files are found by their signatures across the whole image, even after a quick format reset the file table. Pick types such as images, videos, PDF or Office to skip the noise.

    PhotoRec · paranoid, whole space

Built to protect what you recover

The data is often irreplaceable and every extra read wears a failing disc, so the app refuses risky actions instead of trying them.

Safe by design

One tool per image at a time, a free-space check before imaging, and an image is never resumed from a different disc.

Video tools included

Repair carved videos, then cut, join or transcode them, with cancel at any time and the NVIDIA encoder when available.

Stays on this PC

The backend only listens on this computer and every request needs a per-launch token. Nothing is uploaded anywhere.
